Details A–C · systems in production

A3

Commai

2025 · multi-tenant inbox commai.m7corporation.com
Notes
  1. A business’s WhatsApp, Instagram, Facebook Messenger and email conversations in one place, for many tenants.
  2. Each channel has its own webhook endpoint. It checks the provider’s signature, converts the event to one shared format, queues it in Redis and returns 200 straight away, so providers don’t retry under load.
  3. Celery workers store threaded conversations per tenant and generate AI replies.
  4. Adding a channel means writing one webhook handler. Nothing after it changes.
B3

Civic image verification

2025 · Greater Chennai Corporation imageanalysis.gccservices.in
Notes
  1. Checks the before-and-after photos submitted when a civic complaint is marked resolved, and flags fraudulent ones.
  2. A Celery task sends each image to the OpenAI Vision API.
  3. Results are cached in Redis by image signature, so checking the same image again costs no API call.
  4. Runs on EC2, with the images in S3.
C3

Donation platform

2024 · Thaagam Foundation thaagam.org
Notes
  1. Donor records, Razorpay and PayU payments, automatic 80G tax receipts and reconciliation dashboards for the finance team.
  2. Payment webhooks are signature-checked and idempotent, so a retried event is never processed twice.
  3. Receipts go out by email and WhatsApp as soon as a payment is confirmed.
  4. Reconciliation that used to take days now takes under five minutes.
